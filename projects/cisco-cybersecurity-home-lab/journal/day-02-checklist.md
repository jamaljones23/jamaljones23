# Day 2 — Catalyst 3750G Inspection ⬜

**Goal:** Understand the switch's member ID, Ethernet ports, and VLANs before editing any configuration.

## Read-only commands

```text
enable
show switch
show interfaces status
show vlan brief
```

If the command output pauses at `--More--`, press **Space** to continue.

## Questions to answer
- Why does my switch display ports as `Gi2/0/x`?
- Which ports show `connected`?
- Which VLANs exist, and which ports belong to each one?
- Are there unexpected existing settings that should be reviewed before wiring this into the home network?
