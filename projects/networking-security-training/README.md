## Overview

My NexGenT Academy training gave me a foundation in how networks, operating systems, users, and security controls connect. I completed the Full Stack Network Associate program in July 2025 and the NexGenT Cyber Security Associate program in July 2026.

This page summarizes that guided training. It is not a reconstruction of a single independently built network.

## Areas I practiced

| Area | Training focus |
| --- | --- |
| Networking | TCP/IP, DNS, routing, switching, and troubleshooting fundamentals |
| Security concepts | Threats and vulnerabilities, the CIA triad, access control, password security, and risk awareness |
| Lab environments | Working in Windows and Kali Linux environments using VirtualBox |
| Network analysis tools | Practice with Wireshark in a lab environment |

## Why this foundation matters

Understanding normal network and system behavior supports better troubleshooting. These fundamentals help me describe a problem, identify useful questions, and distinguish what has been observed from what still needs to be tested.

My IT support background complements that training: gathering information from a user, communicating clearly, and keeping useful notes all contribute to an organized investigation.

## Evidence and scope

This repository currently contains a written training summary. Individual lab topologies, configuration exports, packet captures, and command-output screenshots have not yet been added.

The next documentation milestone is a networking walkthrough that records the setup, test steps, observed results, and troubleshooting decisions. That future write-up will be listed as completed after its evidence is available.
